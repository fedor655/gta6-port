# gta6rt — загрузчик образа GTA VI

Минимальный нативный загрузчик PE-образа `game_scarlett_master.exe`:

1. читает и разбирает PE32+ (все 10 секций, `.pdata` → 299 257 функций);
2. маппит образ по предпочтительному адресу `0x140000000` и применяет 598 282 релокации `DIR64`;
3. связывает 587 импортов: настоящие Windows-библиотеки через `LoadLibrary`/`GetProcAddress`
   (включая ординалы), Xbox-библиотеки — сгенерированными стабами с логом аргументов;
4. ставит TLS-блок в TEB (`gs:[58h]` и `TlsSlots`), вызывает entry point и печатает первый
   fault с RVA и ближайшей функцией из `.pdata`.

## Сборка

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

Загрузчик намеренно собран с `/BASE:0x10000000 /DYNAMICBASE:NO`, чтобы не занимать адрес игры.

## Запуск

```powershell
.\build\Release\gta6rt.exe "C:\gta6\EXE\game_scarlett_master.exe"
```

| Флаг | Что делает |
|---|---|
| `--map-only` | только маппинг, релокации и биндинг, без запуска |
| `--no-run` | то же плюс TLS, без вызова entry |
| `--no-protect` | не менять права секций (удобно для отладки записи в `.text`) |
| `--trace-iat` | печатать каждый слот IAT с адресом и реальной/стаб-целью |
| `--probe <rva>` | вывести qword по RVA и назвать импорт/регион |

## Что реализовано из xmem

`XMemVirtualAlloc` (трансляция Xbox-флагов в `VirtualAlloc`, резерв для размеров ≥ 4 ГиБ,
fallback на `MEM_RESERVE`), `XMemAlloc`/`XMemFree`. Остальные стабы логируют
`(a, b, c)` и возвращают 0 — этого достаточно, чтобы дойти до CRT-инициализации.

Подробный журнал первых запусков и текущий блокер — [../docs/boot-log.md](../docs/boot-log.md).
